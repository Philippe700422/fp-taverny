Pourquoi cette notice ne dit pas « ouvre le fichier ». Depuis iOS 18, Safari refuse d’ouvrir un fichier HTML enregistré sur l’iPhone : l’app Fichiers l’affiche dans Coup d’œil, un aperçu qui n’exécute pas le JavaScript. Les onglets ne répondent pas, le carnet n’enregistre rien. La seule voie qui fonctionne sur iPhone est d’héberger la page.
Confidentialité. Le dépôt GitHub est public, mais le fichier hébergé ne contient aucune donnée personnelle : ni séances, ni photos, ni mesures. Il ne contient que le programme, les schémas et le code. Comprendre pourquoi on héberge la page

Depuis iOS 18, Safari refuse d’ouvrir un fichier HTML local. L’app Fichiers l’affiche dans Coup d’œil, un aperçu qui montre la page mais n’exécute pas le JavaScript : les onglets, le carnet et le capteur ne peuvent pas fonctionner. Ce n’est pas contournable.

La page doit donc être servie en https. C’est gratuit, ça se fait depuis l’iPhone, et ça règle d’un coup cinq problèmes : ouverture dans Safari, ouverture dans Bluefy, contexte sécurisé exigé par le Bluetooth web, ajout à l’écran d’accueil, et téléchargement des sauvegardes.

Créer un compte GitHub

Dans Safari, va sur github.com → Sign up. Adresse mail, mot de passe, nom d’utilisateur. Compte gratuit, aucune carte bancaire.

Note ton nom d’utilisateur : il fera partie de l’adresse de ton application.

Créer le dépôt

Bouton + en haut à droite → New repository. Nom : fp-taverny. Laisse Public coché — c’est nécessaire pour l’hébergement gratuit. Puis Create repository.

Téléverser les deux fichiers

Dans le dépôt : Add file → Upload files → choose your files → app Fichiers → sélectionne fitness-park-taverny.html et ouvrir-application.html.

Descends en bas de page et appuie sur Commit changes.

Activer l’hébergement

Onglet Settings du dépôt → menu de gauche Pages → section Build and deployment → sous Branch, choisis main puis Save.

Attends une à deux minutes, puis recharge la page Settings → Pages : l’adresse s’affiche. Elle ressemble à https://TON-NOM.github.io/fp-taverny/.

Ouvrir l’application dans Safari

Dans la barre d’adresse, tape ton adresse suivie du nom du fichier : https://TON-NOM.github.io/fp-taverny/fitness-park-taverny.html

Cette fois tout doit répondre. Vérifie les cinq onglets, ouvre une fiche d’exercice, reviens en arrière. Mets la page en favori.

Lancer le diagnostic dans Safari

Onglet Diagnostic. Contexte sécurisé doit être vert — c’est le bénéfice direct de l’hébergement. Bluetooth web restera absent : c’est normal, Safari ne le propose pas.

Appuie sur Tester un téléchargement et vérifie que le fichier arrive dans Fichiers → Téléchargements.

Ouvrir la même adresse dans Bluefy

Copie l’adresse depuis Safari, ouvre Bluefy, colle-la dans sa barre d’adresse. Mets la page en favori dans Bluefy : ce sera ton accès quotidien.

Relance le Diagnostic : Navigateur doit indiquer Bluefy et Bluetooth web passer à « disponible ».

Le lanceur sur l’écran d’accueil

Dans Safari, ouvre …/ouvrir-application.html. Renseigne une fois l’adresse complète de l’application dans le champ du haut : elle est mémorisée.

Puis Partager → Sur l’écran d’accueil, nomme-la Fitness Park. À chaque appui, elle te demandera avec quel navigateur ouvrir.

Régler la destination des téléchargements

Réglages → Safari → Téléchargements → iCloud Drive. Les sauvegardes automatiques du carnet y atterriront directement.

Appairer le Polar Verity Sense

Allume le capteur, place-le sur l’avant-bras, et vérifie qu’il n’est pas déjà connecté à une autre application : un capteur BLE ne se partage pas toujours.

Dans Bluefy, ouvre une séance du carnet, bloc Fréquence cardiaque → Connecter le capteur → choisis Polar Sense. La FC s’affiche en direct.

Ajouter tes premières photos

Onglet Photos. Deux emplacements par machine : la machine avec son environnement, et l’autocollant du fabricant. Elles apparaissent aussitôt sous les schémas du programme.

Six machines par séance suffisent — inutile de tout faire d’un coup.

Partie 2 — Mode d’emploi Ce que fait chaque onglet, comment s’en servir en séance, et quoi faire quand ça coince.

Onglet Programme

Ta semaine : J1 Push, J2 Pull, J3 Legs, J5 Upper, J6 Lower. Les onglets filtrent l’affichage sur un seul jour ; Tout les montre ensemble. Repères et Méthode ouvrent les pages de fond : codes de zones, règles, protection des genoux, choix des charges.

Chaque ligne d’exercice affiche le schéma en vignette, le nom, le tag anglais de l’autocollant, la consigne du jour et les séries. Deux actions :

  • Appuyer sur la ligne ouvre la fiche complète.
  • Appuyer sur ＋ carnet saute directement à la saisie de cet exercice.

Dans une fiche tu trouves, dans l’ordre : le schéma de repérage — les parties en orange bougent —, tes photos si tu en as ajouté, les deux liens photo vers les fiches produit Technogym et Hammer Strength, les fiches officielles complémentaires, la consigne du jour, comment reconnaître la machine, les pièges de confusion, les muscles, les réglages, l’exécution pas à pas, les erreurs fréquentes et la solution de repli si la machine est occupée. En bas, la navigation vers l’exercice suivant.

Onglet Carnet

Choisis la séance du jour, ou reprends une séance passée depuis l’historique pour la corriger. Une séance se compose de cinq blocs, dans l’ordre où ça se passe réellement :

BlocCe que tu y saisis
Fréquence cardiaqueFC moyenne et max. Remplies automatiquement si le capteur est connecté, sinon recopiées depuis Polar Flow.
ÉchauffementAppareil, programme, durée, niveau, distance, calories, FC, watts. La consigne du jour est rappelée dans le bloc.
Les six exercicesCharge, répétitions, RIR pour chaque série. Boutons − série et + série pour coller à ce que tu as vraiment fait.
Abdos & gainageJusqu’à six exercices, chacun en secondes, répétitions ou kilos selon la nature du mouvement.
Cardio de finMêmes champs que l’échauffement.

Le rappel « dernière fois » s’affiche sous chaque exercice, chaque bloc cardio et chaque exercice d’abdos. C’est lui qui déclenche la règle du programme : trois séries propres à RIR 2, donc +2,5 kg la semaine suivante.

Le chronomètre de repos est préréglé sur le temps de chaque exercice — 90, 75, 60 ou 45 secondes. La barre reste visible en bas de l’écran et passe en orange pendant le décompte.

RIR — répétitions en réserve. Le nombre de répétitions que tu aurais encore pu faire proprement. Ton programme demande de t’arrêter à 2. Les deux premières semaines, garde-en 3 ou 4 : la priorité est la technique.

Onglet Photos

Les 23 machines, dans l’ordre où tu les rencontres au fil des séances. Deux emplacements par machine : la machine entière avec son environnement, et l’autocollant du fabricant. Les images sont compressées automatiquement avant d’être stockées.

Elles apparaissent immédiatement dans les fiches du programme — aucune régénération de fichier. Le bouton Exporter mes photos produit un fichier séparé du carnet.

Photos et séances partagent la même mémoire. Si le bandeau de saturation apparaît, exporte tes photos ou retires-en quelques-unes : ton carnet est prioritaire.

Onglet Fiches produit

Pour chaque machine, deux liens photo — une fiche Technogym, une fiche Hammer Strength Select — et en dessous les fiches officielles complémentaires et les catalogues. Ces liens demandent une connexion ; tout le reste de l’application fonctionne hors ligne.

Quand Technogym n’a pas de fiche publique pour un modèle, le lien ouvre la brochure Selection et une ligne grise t’indique le nom à chercher dans le sommaire.

Onglet Diagnostic

Trois usages : vérifier ce que ton navigateur accepte, extraire tes données quand le téléchargement ne fonctionne pas, et recharger une sauvegarde.

  • Afficher la sauvegarde / le CSV puis Copier le texte affiché : ta sortie de secours.
  • Restaurer depuis le texte collé : recolle une sauvegarde prise dans une note.
  • Restaurer depuis un fichier : si ton navigateur sait ouvrir un .json.
La restauration fusionne, elle ne remplace jamais. Les séances déjà présentes ne sont pas dupliquées. Tu peux recoller dix fois la même sauvegarde sans salir tes données.

Sauvegarde — la partie à ne pas négliger

Safari efface le stockage local d’une page après sept jours sans ouverture. C’est une mesure anti-pistage d’Apple, pas un défaut de l’application. Tes séances ne sont donc jamais garanties dans la mémoire du navigateur.

L’application dépose automatiquement un fichier carnet-AAAA-MM-JJ.json à chaque séance enregistrée. Chaque fichier contient la base entière : le plus récent suffit toujours à tout restaurer, les précédents peuvent être supprimés.

FréquenceCe que tu fais
Chaque séanceRien — la sauvegarde part toute seule si le téléchargement fonctionne.
Chaque semaineVérifie que le bandeau d’accueil du carnet est gris et non orange.
Chaque moisCopie la sauvegarde dans une note ou range le .json dans iCloud Drive.
Tous les deux moisArchive les séances anciennes si tu veux alléger le carnet.

Exports et applications santé

Aucune page web ne peut écrire dans l’app Santé d’Apple : cet accès est réservé aux applications natives. Le chemin qui fonctionne passe par un intermédiaire.

  • CSV détaillé — une ligne par série, avec le type (cardio début, musculation, abdos, cardio fin), la durée, le niveau, la distance, les calories, la FC. Pour Numbers ou Excel.
  • CSV format Strong — importable dans Strong ou Hevy, qui écrivent ensuite dans Santé. Le RIR y est converti en RPE.
  • Sauvegarde .json — ta base complète, pour restaurer.

Dépannage

Le bouton « Connecter le capteur » n’apparaît pas.
Tu n’es pas dans Bluefy, ou le contexte n’est pas sécurisé. Vérifie ces deux lignes dans le Diagnostic.
Le capteur ne se connecte pas.
Il est probablement déjà relié à Polar Flow ou à une montre. Ferme l’autre application, ou active le double Bluetooth dans les réglages Polar Flow.
Mes séances ont disparu.
C’est la règle des sept jours. Onglet Diagnostic → recharge ta dernière sauvegarde, par collage ou par fichier.
Le téléchargement ne produit aucun fichier.
Ce navigateur ne sait pas télécharger. Utilise systématiquement la sortie de secours : afficher, copier, coller dans une note.
Une photo refuse de s’ajouter.
Mémoire saturée. Exporte tes photos, puis retires-en quelques-unes. Les autocollants sont les plus utiles à garder.
Un lien de fiche produit tombe en erreur.
Signale-le-moi, je le corrige. Les fiches Hammer Strength ont été construites sur un motif d’URL vérifié, mais un fabricant peut réorganiser son site.
J’ai saisi une séance dans le mauvais jour.
Ouvre-la depuis l’historique, note les valeurs, supprime-la, ressaisis-la dans le bon jour.
